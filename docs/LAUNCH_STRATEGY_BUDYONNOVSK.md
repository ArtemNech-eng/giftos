# Стратегия запуска первого города — Будённовск

## Проблема cold start

Пустой город нельзя запускать с посылом «создай первое место». Большинство людей не хотят быть первыми в пустой социальной сети.

Это не проблема дизайна или SEO — это проблема социальной плотности.

## Принцип запуска

До появления достаточной активности город показывается как **предзапуск сообщества**, а не как уже работающий город.

```text
Не: «В городе пока никого нет»

А: «Открываем Будённовск вместе»
    «Собираем первых жителей, места и авторов»
```

## Минимальная плотность перед публичным запуском

До масштабного внешнего трафика собрать вручную:

- 20–50 первых жителей;
- 5–10 авторов / локальных амбассадоров;
- 3–5 заранее оформленных мест;
- 2–3 первых события;
- несколько публичных желаний и stories;
- один live/creator-сценарий по расписанию.

В production нельзя выдавать демо-активность за реальную. Синтетические записи допустимы только для разработки/демо с явной маркировкой.

## Первая ценность для жителя

Пользователь не обязан первым создавать место. Он должен получить выбор:

```text
Присоединиться к месту
Посмотреть людей рядом
Отметить своё желание
Прийти на событие
Позвать своего человека
```

## Сценарий амбассадора

```text
Амбассадор получает creator-страницу
→ открывает место / тусовку
→ приглашает 10–30 знакомых
→ публикует stories / событие / желание
→ получает статус и ⭐ за активных приглашённых
→ становится локальной точкой притяжения
```

## UI до и после порога плотности

### Предзапуск

```text
Открываем Будённовск
Стань одним из тех, кто соберёт город
[ Присоединиться ]
[ Посмотреть, что появится ]
```

### Активный город

```text
Будённовск сейчас
Места · люди · stories · эфиры · события
[ Куда пойдём? ]
```

Переключение должно зависеть от реальных метрик активных жителей, мест и сообщений, а не от ручной иллюзии.

### Текущий автоматический UI-порог

Landing вычисляет состояние по реальным публичным данным города:

```text
0–1 публичный житель
→ «Открываем город»

от 2 публичных жителей
→ «Город уже собирается»

от 20 публичных жителей + 3 пользовательских активных места + 2 будущих события
→ «Город сейчас»
```

Фиксированные стартовые места не засчитываются в порог активного города. Это не отменяет ручную launch-проверку качества из раздела «Минимальная плотность», а только меняет честный текст и CTA на landing.

## Каналы набора первой плотности

- локальные Telegram/VK-чаты;
- микроавторы и организаторы;
- студенческие/спортивные/игровые сообщества;
- места с реальной аудиторией: кафе, спорт, музыка, игры;
- локальные события и партнёры;
- личные приглашения амбассадоров.

## Метрики готовности города

- активные жители за 7 дней;
- активные места;
- сообщений на активное место;
- повторные визиты D1/D7;
- приглашения на активного жителя;
- число созданных желаний/stories/событий;
- первая test/real creator-операция.
