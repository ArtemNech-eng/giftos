# MVP backlog

## Definition of Done для каждой задачи

- Сценарий проверен с авторизованным и неавторизованным пользователем.
- Доступ проверяется RLS, а не скрытием кнопки в UI.
- Есть загрузочное, пустое и ошибочное состояния.
- Зафиксированы аналитическое событие и критерий модерации, если сценарий социальный.
- Суммы — только в minor units; секреты — только на сервере.

## Рефералы — после основной воронки

Условие квалификации не привязано к простому факту регистрации. Предварительный вариант: реферал должен подтвердить контакт, заполнить профиль и выполнить значимое действие (создать опубликованный сбор **или** сделать подтверждённую поддержку). Затем запись получает статус `held` на 14–21 день. Одобрение — отдельный процесс с лимитами и проверкой подозрительных паттернов; конкретное экономическое вознаграждение согласуется отдельно.
