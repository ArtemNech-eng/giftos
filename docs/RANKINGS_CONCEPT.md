# Концепция «Социальный рейтинг и экономика внимания» (Дополнение к ТЗ №5)

**Статус:** дополнение к основному плану, получено от руководителя (обсуждено 6 августа 2026).

## Главная идея

Пользователь стремится стать **заметной личностью своего города**. Социальный статус — ключевая мотивация. Эмоция: **«Я хочу, чтобы меня знали в моём городе»**.

Рейтинг — потенциальный **двигатель всей платформы**: он создаёт естественные причины приглашать друзей («хочу стать №1 в городе»), а деньги получают смысл как инструмент заметности, а не самоцель.

## Ключевые тезисы

1. **Рейтинг города** — у каждого города свой топ (👑 ⭐ 🔥 💎 🚀), обновляется в реальном времени.
2. **Рейтинг нельзя продавать напрямую** — нельзя «купил VIP → №1». Платные функции дают инструменты (показы, продвижение, оформление), которые увеличивают внимание, а внимание уже даёт активность и место.
3. **Факторы рейтинга**: активность, подписчики, посещаемость эфиров, развитие тусовки, приглашённые и их удержание, события, достижения, регулярность. Алгоритм гибкий, меняется в SQL без изменения клиента.
4. **Несколько рейтингов** (не один общий):
   - 👑 ТОП пользователей города;
   - 🏠 ТОП владельцев тусовок;
   - 🎤 ТОП авторов эфиров;
   - 📈 Самый быстрорастущий за неделю;
   - 🤝 Самый общительный.
5. **Репутация / социальные роли** за реальные достижения: 👑 Легенда города, ⭐ Амбассадор, 🏠 Лидер сообщества, 🎤 Лучший ведущий, ❤️ Душа города, 🚀 Открытие недели. Отображаются в профиле, чатах, эфирах, списках.
6. **Главный цикл**: общение → внимание → желание стать популярнее → развитие профиля/тусовки → приглашения → эфиры → аудитория → заработок → выше рейтинг → ещё больше внимания → снова рост.
7. **Рейтинг — центральный экран города**: открывая город, видишь кто сегодня популярен, какие тусовки растут, кто ведёт горячие эфиры, кто поднялся за неделю.

## Техническая оценка (6 августа 2026)

### Уже готово

- `city_rank` (позиция по подписчикам), уровни статуса, лидеры тусовок, самые активные, битва городов, продвижение за ⭐.

### Нужно достроить

- **Этап 1 (рейтинги):** view `public_city_rankings` с категориями (top/hangout/streamer/rising/social) и составным score (активность 40% / вклад в город 25% / тусовка 20% / автор 15%); центральный экран рейтингов с табами.
- **Этап 2 (репутация):** функция `reputation_roles(profile_id)` по порогам достижений; отображение ролей в профиле и рядом с именем.
- **Этап 3 (интеграция):** роли в чатах/эфирах/списках участников; «кто поднялся за неделю» на экране города.

### Правила (не нарушаются)

- Рейтинг не продаётся: платное только увеличивает внимание.
- Пороги ролей и веса факторов настраиваются в SQL/настройках.
