# Статус продукта «Хочу также» — итоговая сводка

**Дата:** 2026-08-08 · **Ветка:** `arena/019fd2fe-giftos` · **Миграций:** 100 · **Коммитов:** ~220

## Что это

«Хочу также» — социальная creator-платформа с городом как точкой входа: желания, сборы, места, тусовки, эфиры, stories, рейтинги, экономика ⭐, коллекционные артефакты. Первый город запуска — **Будённовск**.

## Дизайн-система (v2, завершена)

- **Единый premium soft light** на всех экранах: лента, город, места, люди, события, желания, сборы, эфиры, stories, профиль, поиск, бонусы, магазин, битва городов, рейтинги, панель автора, галерея, настройки, онбординг, SEO-главная.
- **Намеренно тёмные зоны:** только видео-плеер (live/story) и плавающий bottom-nav.
- **Семантические иконки вместо OS-эмодзи:** `WishCategoryIcon`, `PlaceIcon`, `PlaceEmblemIcon`, `VirtualItemIcon`, `EventTypeIcon`, `LocalRoleIcon`, `BrandGiftIcon`; в презентации остался только ⭐ (фирменная валюта).
- **Noauth preview-каталог** `/preview?screen=…` — 27 экранов (все отвечают 200).
