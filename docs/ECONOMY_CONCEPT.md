# Концепция «Экономика продукта и замкнутый социальный цикл» (Дополнение к ТЗ №3)

**Статус:** дополнение к основному плану, получено от руководителя (обсуждено 6 августа 2026).

## Главный принцип

Монетизация встроена в социальную механику с самого начала, а не добавлена потом.

```
Пользователь → Тусовка → Внимание → Виртуальные товары → Подарки → VIP → Продвижение → Авторы → Комиссия
```

## Два независимых источника выручки

- **A. Доход от пользователей — 100% платформе:** VIP, цифровые товары (персонажи, аватары, рамки, эффекты, оформление профиля/тусовок), продвижение (профиль/эфир/тусовка/событие), закрепление, платные функции.
- **B. Экономика авторов — комиссия платформы:** целевая модель 80% автору / 20% платформе (донаты, подарки авторам, подписки, платные сообщения).

## Ключевые требования

1. Разделять **подарки платформы** (100% платформе, не денежное вознаграждение автора) и **поддержку/донаты авторов** (80/20).
2. Виртуальные товары не выводятся обратно в деньги.
3. VIP — необязательная подписка: социальные функции остаются бесплатными.
4. Социальный статус (Новичок → Активный → Популярный → Автор → Звезда) не определяется только деньгами — активность важнее.
5. Монетизация тусовок: оформление, темы, эмблемы, премиальные функции для создателей.
6. Отдельный финансовый модуль (начисление, вывод, комиссия, пороги, возвраты, антифрод) — после юридической модели.
7. Метрики: ARPU, ARPPU, % платящих, средний чек, доход по моделям, LTV.

## Открытые решения (нужен ввод руководителя)

1. Тестовый режим: магазин/VIP/продвижение **сначала за ⭐** (реальные деньги — после платёжного партнёра).
2. Какие подарки платформенные, какие авторские (признак в каталоге / разделение).
3. Цены и бонусы VIP.
4. Пороги уровней статуса.

## Принятые решения (6 августа 2026)

1. ✅ Магазин, VIP и продвижение — **сначала за ⭐**; реальные деньги — после платёжного партнёра.
2. ✅ **Подарки «как в Telegram»**: каталог подарков с ценой в ⭐, покупка и дарение между пользователями, подарок отображается в профиле получателя. Без cash-out и обмена на деньги.
3. ✅ **VIP — 149 ⭐/мес**: значок VIP на профиле, рамка профиля, бонус (1 бесплатное продвижение в месяц).
4. ✅ **Уровни статуса** (по подписчикам/активности, пороги настраиваемые):
   - Новичок — 0+
   - Активный — 5+ подписчиков
   - Популярный — 50+
   - Автор — 500+
   - Звезда — 5000+

## Границы (не нарушаются)

- ⭐ не выводятся в деньги; свободный обмен подарков между пользователями запрещён.
- Вывод средств авторам — только после KYC/возраста и юридической модели.
- Платёжный партнёр — в самом конце (по договорённости).
