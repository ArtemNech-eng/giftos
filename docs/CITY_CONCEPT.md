# Концепция «Город как точка входа»

**Статус:** дополнение к основному плану, получено от руководителя (обсуждено 5 августа 2026).

**Первый город запуска:** Будённовск (примеры в исходном документе с Aachen — шаблонные, заменяются на Будённовск).

## Главный принцип

> **Город локальный. Платформа — глобальная.**

Город — не отдельная соцсеть и не ограничение. Это первая точка входа, способ найти знакомых рядом, основа локального сообщества, механизм органического запуска и соревнования. После регистрации пользователь получает доступ ко всей платформе без ограничений.

## Ключевые тезисы

1. **Первый запуск — один город.** Задача — ощущение «здесь уже есть люди, которых я знаю». Формулировки: «Соберём Будённовск вместе», «Первые жители уже здесь», «Пригласи своих».
2. **Главная города:** Люди рядом, Сейчас в эфире, Новые, Популярные, Активные, Популярные желания. Лента показывает людей и активность, а не только сборы.
3. **Доступ ко всей платформе** свободный: поиск, подписки, эфиры, сообщения, подарки, донаты, подписки на авторов, совместные эфиры, желания, заработок — без ограничений по городу.
4. **Два уровня ленты:** «📍 Мой город» (жители, локальные эфиры/события, новые и популярные пользователи) и «🌎 Вся платформа» (популярные авторы, рекомендации, интересы, другой контент). Свободное переключение.
5. **Город не влияет на заработок автора.** Схема: автор → аудитория всей платформы → монетизация. Донат/платное сообщение из другого города — обычная операция.
6. **Рекомендации между городами** («Люди, которые могут тебе понравиться»): учитывают интересы, подписки, просмотры, активность, эфиры, взаимодействия, общие желания и подписчиков.
7. **«Люди рядом»** — отдельная локальная механика (общение, знакомства, единомышленники, совместные активности), но продукт не позиционируется исключительно как сервис знакомств. Учитывать `show_city` (приватность).
8. **Локальные интересы:** поиск «Бег» → «Люди из Будённовска, которые любят бег» + «и ещё 4 200 пользователей платформы».
9. **«Хочу также» между городами:** общий интерес связывает людей из разных городов — формирует межгородские связи.
10. **Соревнование городов «Битва городов»:** баллы за новых активных пользователей, приглашения, эфиры, активность, публикации, взаимодействия. Заработок пользователей не является собственностью города.
11. **Мотивация:** «Aachen/Будённовск сейчас второй, до первого места 4 371 балл — пригласи друга и помоги городу победить». Приглашение становится групповой активностью.
12. **Награда победителю сезона:** общий городской ивент/фестиваль, статусы жителям, бонусы, «Кубок города». Награда общая — «мы выиграли вместе».
13. **Локальные события** (после роста аудитории): встречи, спорт, прогулки, турниры, концерты, совместные эфиры. Событие может быть локальным или открытым для всей платформы.
14. **Масштабирование:** Будённовск → +Кöln/Düsseldorf (или соседние города) → крупные города → страна → другие страны. База не разделяется: все города — одна соцсеть.

## Итоговая модель роста

```
один город на старте
→ люди находят знакомых и интересных людей рядом
→ приглашают друзей (город растёт)
→ локальное сообщество
→ доступ ко всей платформе
→ люди из других городов, своя аудитория
→ эфиры, подписчики
→ донаты / подарки / платные сообщения / подписки
→ заработок независимо от города аудитории
```

## Техническая оценка (5 августа 2026)

### Уже готово в коде

- `profiles.city` + `show_city` (приватность показа города);
- поиск людей по городу (только при `show_city`);
- лента live-комнат (фильтруема по городу);
- персональные рекомендации авторов;
- реферальная система (основа «приведи друга в город»);
- вся монетизация глобальна (донаты, подарки, подписки, эфиры, платные сообщения);
- город на странице профиля.

### Нужно достроить

- **Этап 0 (фундамент):** ✅ справочник `cities` + нормализация `profiles.city` → `city_id` (миграция 36), город в onboarding с подсказками из справочника; ⏳ определение города по IP (отложено — нужен внешний гео-сервис, решить с руководителем).
- **Этап 1 (городская лента):** ✅ переключатель «📍 Мой город / 🌎 Вся платформа» в feed; ✅ секции «Люди рядом», «Сейчас в эфире · город», «Новые жители», «Желания города»; ✅ fallback на платформенный контент при пустом городе/без города. «Активные» (по активности) — можно добавить позже на основе метрик.
- **Этап 2 (виральность):** реферальная ссылка с городом; «Битва городов» (баллы за квалифицированные действия с антифродом по паттерну рефералов: hold-период и проверка активности; сезоны; таблица лидеров).
- **Этап 3:** локальные события (локальные/открытые).

### Риски

- Пустая городская лента в первые недели → обязательный fallback.
- Город — ПДн → «Люди рядом» и городская лента показывают только пользователей с `show_city = true` и публичным профилем.
- Накрутка баллов в «Битве городов» → антифрод и квалификация действий с самого начала.
