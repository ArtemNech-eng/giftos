# Визуальный прототип экранов «Хочу также»

**Источник:** прототип экранов, переданный 5 августа 2026.

## Визуальное направление

- Mobile-first интерфейс с тёмной основой.
- Акцентные градиенты: розовый → фиолетовый.
- Компактные круглые аватары в ленте и списках.
- Карточки с мягкими скруглениями, крупными CTA и понятными ценами.
- Главный объект — авторская страница, а не товарная карточка.

## Экраны из прототипа и их назначение

| Экран             | Назначение                                                               | Статус в текущем roadmap                                                                               |
| ----------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| Главная           | Stories, активные авторы, «можно пообщаться», интересы, нижняя навигация | Делать после первой story-механики; live-блок пока заменяется на stories                               |
| Профиль автора    | Автор, интересы, статистика, подписка, доступные действия, вкладки       | Базовый профиль и creator mode уже есть; нужна визуальная переработка и offers                         |
| Просмотр контента | Полноэкранный формат, чат/реакции, подарки                               | На первом этапе — viewer video story, не live-эфир                                                     |
| Платное сообщение | Экран доступа к запросу на сообщение                                     | Должен работать как добровольно принятый платный запрос, а не покупка гарантированного личного доступа |
| Доход автора      | Баланс, динамика, источники дохода, история                              | Сначала тестовый ledger без настоящей выплаты; production payouts — после KYC/партнёра                 |
| Создание эфира    | Медиа, название, категория, правила                                      | Отложено: сначала создаём экран/сценарий создания video story                                          |

## Адаптация под текущий порядок работ

В прототипе есть эфиры, совместные эфиры и вывод денег. В ближайшем срезе они заменяются следующим:

```text
«Сейчас в эфире» → «Новые video stories»
Экран эфира → полноэкранный viewer story
Создать эфир → создать video story
Донаты в эфире → тестовое платное открытие story / tip позже
Вывод денег → тестовый баланс автора, без cash-out
```

## Неподвижные safety-принципы

- Денежные creator-функции и выплаты — только 18+ после age verification/KYC.
- Платёж не обходит блокировку, настройки приватности и согласие пользователя.
- Платное сообщение — запрос, который автор принимает до списания/выплаты, либо tip без обещания ответа.
- Визуальная модель дохода не означает, что реальный вывод денег уже реализован.

## Следующая UI-работа

После проверки stories переработать текущую веб-ленту и профиль по этому референсу:

1. Тёмная mobile-first тема как отдельный creator experience.
2. Круг stories наверху главной.
3. Карточки авторов с компактным аватаром и понятным CTA.
4. Профиль автора с вкладками «Обо мне / Stories / Посты».
5. Полноэкранный story viewer и экран тестового unlock.
